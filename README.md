# Trazabilidad de cacao - II Hackathon USCO

## Material previo declarado
Next.js (create-next-app, licencia MIT), Tailwind CSS, Clerk y Supabase. No se uso codigo previo del reto.

## Instalacion
1. git clone https://github.com/BrayanRK/cacao-trazabilidad.git
2. cd cacao-trazabilidad
3. npm install
4. Copiar .env.example a .env.local y completar los valores
5. npm run dev  ->  http://localhost:3000
